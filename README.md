## 🚀 Overview

**TuneCraft** brings real music to your server — not vanilla note blocks.

* 🎧 Actual `.ogg` songs, streamed through a resource pack
* 📍 Positional audio zones based on distance
* 🎚️ Per-player volume control
* 🔄 Auto-generated resource pack, zero manual packing

Built for servers that want **atmosphere without the hassle**.

---

## ✨ Key Features

### 🎵 Custom Songs

* Drop `.ogg` files into the `songs` folder
* Plugin auto-builds the resource pack for you

### 📍 Positional Zones

* A player starts a song at their location
* Nearby players hear it with distance-based volume falloff

### 🖱️ In-Game Menu

* Browse and play songs through `/music`
* No need to memorize song names

### 🎚️ Volume Control

* Each listener adjusts their own volume independently

---

## 🎮 Commands

```
/music
/music stop
/music reload
```

## ⚙️ Permissions

| Permission     | Description                                     | Default |
| -------------- | ------------------------------------------------ | ------- |
| `music.reload` | Allows rebuilding the resource pack and reload    | op      |

---

## 📦 Installation

1. Drop `TuneCraft.jar` into your `plugins` folder
2. Restart the server
3. Add `.ogg` files to `plugins/TuneCraft/songs/`
4. Run `/music reload`
5. Players reconnect to load the resource pack
